How the Jazz composition tool works

One agent call turns a plain-English description into a single, self-contained HTML file you can open, share, or publish — no build step, no dependencies, no server.

02 What it can build

A live page for hover, filters, sliders and games. Every control is real DOM — no framework. State deep-links via query params, so a configuration is a shareable URL.

// one file: html + css + js, zero dependencies const act = document.querySelector('input[type=range]'); act.addEventListener("input", () => { state.rate = +act.value; render(); // re-draw the SVG / recompute save(); // → ?rate=400 — shareable });

16:9 slides with keyboard, click and touch navigation, #n deep links, a progress line and per-slide speaker notes. Built on the View Transitions API for a native-feeling morph between slides.

// navigate + deep link addEventListener("keydown", (e) => { if (e.key === "ArrowRight") go(i + 1); if (e.key === "ArrowLeft") go(i - 1); }); // #3 opens straight onto slide three

Inline, side-by-side or wizard layouts using native inputs — with blur validation, empty states and offline persistence (URL params + localStorage). Works as a capture-and-export surface for the agent.

// offline persistence form.addEventListener("submit", (e) => { e.preventDefault(); localStorage.setItem("draft", JSON.stringify(data)); // or export a download / copy to clipboard });

Hand-rolled SVG: flow diagrams, sequence diagrams, ERDs, architecture. Every path uses pathLength="100" so line-draw animation is uniform, and even gaps keep arrowheads clear of the nodes.

<!-- uniform draw-in regardless of length --> <path class="edge draw" pathLength="100" d="M180,150 L250,150" />

03 The anatomy of the file

Every composition is one HTML document with a consistent house design system: one accent color per piece, the whole palette derived from it, and motion that is choreography, not decoration. It degrades gracefully for reduced-motion users.

Single .html file Zero dependencies Works offline No build step One accent + derived palette prefers-reduced-motion safe Query-param deep links

04 How a request becomes a page

1

Describe it

You ask for what you want — "an interactive explainer of how X works" — the agent picks the right layout (sim, deck, form or diagram).

2

The agent writes the HTML

create_composition emits a complete, self-contained file — markup, tokens, motion and JS all inline.

3

Saved to the session

It lands at ~/.jazz/compositions/<session>/<name>.html and opens in your browser automatically.

4

Iterate or publish

Tweak it in the chat, or publish_composition pushes it to a stable, shareable URL.

05 Take it further

This whole flow runs inside the Jazz CLI. Install it, talk to an agent, and compositions just appear in your browser.
